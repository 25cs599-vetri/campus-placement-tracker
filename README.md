# PlaceTrack - Campus Placement Preparation Tracker

A web-based application designed to help students manage their placement preparation in one place.

PlaceTrack helps students track coding practice, daily preparation tasks, placement applications, interviews, and personal career details.
## Features

- Manage daily preparation tasks.
- Track DSA problems by topic and difficulty.
- Mark coding problems as solved.
- Track placement applications.
- Update application status.
- Monitor interview progress.
- Save student profile details.
- Store data using browser Local Storage.
- Responsive design for desktop and mobile devices.
## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage
## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in Google Chrome or any modern browser.
4. Start managing your placement preparation!
